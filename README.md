# 心绪气象站 · Inner Weather

一个三步完成的轻量互动体验：写下（或略过）心事，选择一种心情天气，收下一张可以复制的微型明信片。它是一个独立的新项目，面向自我觉察与轻量数字内容体验。

## 本地运行

需要 Node.js 18 或更新版本。

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

## 用户流程

1. 用户可选填一句当下的心事（最多 100 字）。
2. 从四种原创天气意象中选择一种：晴间多云、正在下雨、风有点大、薄雾时分。
3. 查看对应的反思卡片，可复制保存或重新开始。

## 项目结构

```text
App.jsx          页面流程、状态和交互
reflections.js   天气选项及原创反思文案
main.jsx         React 入口
style.css        响应式页面样式
index.html       页面入口及元信息
```

## 技术和工作流

- React：将三步体验拆成明确的页面状态和可复用数据。
- Vite：本地开发与静态生产构建。
- CSS：自适应布局、天气卡片与明信片视觉。
- 浏览器 Clipboard API：由用户主动复制卡片内容。
- 本地数据：不需要服务端、账号、API 密钥、摄像头或外部 AI 服务。填写的文字只保存在当前页面状态中。

## 项目边界与设计原则

反思文案是陪伴式内容，不做诊断、预测或治疗承诺。用户可以跳过输入，也可以随时重新开始。选择、呈现、保存是一条短且可理解的互动路径。

项目参考了《命运之镜》“输入—选择—揭示—反思”的交互节奏；本项目的主题、文案、内容数据和界面实现均为新创作，不复用其源码或塔罗素材。

## 项目与专业方向

- **IMS**：小型数字产品原型，呈现用户路径、状态转换、前端实现与隐私边界。
- **MMGT**：以微内容和品牌语气为核心，呈现内容主题、受众触点与可分享的内容单元。

以上是项目设计目标，不代表已完成用户研究或验证。后续可通过小范围可用性测试检查天气选项是否易懂、用户是否愿意保存卡片，再据观察调整内容。
